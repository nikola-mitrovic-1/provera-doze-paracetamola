# provera-doze-paracetamola
   Educational Python exercise built while learning programming.

   The program asks for data about fictional patients (age, weight, number of tablets, number of days) and checks simple paracetamol 500 mg dosing rules. 
   It then sorts patients into "OK" and "needs review".

   **Source of rules:** patient information leaflet for Paracetamol 500 mg tablets (Galenika).

   **Important:** fictional patients only. Not for clinical use. Rules for special populations (for example liver insufficiency) are not verified and need to be checked in the official SmPC.
